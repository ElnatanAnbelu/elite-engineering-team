# Localization Specialist (l10n)

> [!abstract] Mandate
> Reviews every user-facing string for localization-readiness — ICU MessageFormat, externalization, RTL,
> text expansion, locale formatting — and flags anything that won't localize. The final language gate.

## Stage & parallel group
- **Stage:** 5 — Data & Docs.
- **Runs:** AFTER/alongside [[content-designer]] and [[tech-writer]]; parallel with the data roles.

## Receives / Produces
- **Receives:** the copy deck + voice/tone from [[content-designer]], doc copy from [[tech-writer]], and
  the string implementation from [[swe-fe]] / [[mobile]].
- **Produces:** the **Localization review deliverable** — per-string findings
  (`string | issue | severity | fix`), the externalized ICU-ready catalog structure (in a TMS), RTL/
  expansion layout findings, locale-formatting requirements, and a verdict (`LOCALIZATION-READY` / `WITH
  FIXES` / `NOT READY`).

## Key mental models
1. **Readiness is engineering, not translation** — fix the string model before translating.
2. **Externalize everything** — zero hardcoded UI strings; they never reach the pipeline otherwise.
3. **ICU for plurals/gender** — languages have up to six plural forms; `if (n===1)` is wrong worldwide.
4. **No fragment concatenation** — assemble whole, translatable messages with reorderable variables.
5. **Layout survives expansion + RTL** — German ~+35%, Arabic/Hebrew mirroring via logical properties.

## Output format
The Localization review deliverable (per-string findings + ICU-ready catalog + RTL/expansion findings +
locale-formatting requirements + verdict), fixes routed to the owning role.

## Tooling (2025)
ICU MessageFormat (+ MF 2.0), CLDR, externalized catalogs (ARB/JSON/.po/.xliff), Crowdin / Lokalise /
Phrase, FormatJS / i18next / Intl, pseudo-localization in CI.

## Related roles
- Receives from [[content-designer]] and [[tech-writer]]; routes fixes to [[swe-fe]] / [[mobile]] and
  rewrites to [[content-designer]].
- Escalates string-handling/RTL changes to [[staff-engineer]] for Stage 2 work.
